# Agent Skills Exchange — Briar harness

A lightweight home for independently usable Agent Skills and an optional Briar
core. The implementation is being prepared on a development branch; this initial
base does not contain a released package or a replacement for a live harness.

Original contributions are licensed under GPL-3.0-or-later. See LICENSE for the
GPLv3 text; the grant permits version3 or, at your option, a later version.
Third-party work retains its own licences and notices.

The intended core supports on-demand pinned skills, explicit dependencies and
non-interactive operation. Those are delivery requirements, not claims that
authentication, admission, host integration or migration has already passed.
